# Kinora

Kinora is a private AI creative studio for building images, motion, reusable characters, and organized visual projects.

## v0.1 foundation

The first build includes:

- Dashboard
- Create studio
- Characters
- Projects
- Generation history
- Responsive app shell
- Next.js + TypeScript + Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
